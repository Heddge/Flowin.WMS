# Flowin.WMS

**Flowin.WMS** — проект системы управления складскими процессами (Warehouse Management System). Система автоматизирует внутренние процессы сортировочного центра: приёмку товаров, размещение на складе, управление остатками, резервирование, комплектацию заказов, упаковку, перемещения и инвентаризацию. Проект ориентирован на надёжность, целостность данных и корректную обработку конкурентных операций.

**Стек:** Java, Spring Boot, PostgreSQL, Redis, RabbitMQ, Apache Kafka, Docker, Kubernetes, Maven, GitHub Actions, JUnit, Mockito.
